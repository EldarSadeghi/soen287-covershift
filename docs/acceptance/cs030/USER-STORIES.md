## Scope and limits

Recorded AI replies exercise production workflow handling, not real-model language accuracy. Browser checks cover representative paths and measured viewport/keyboard behavior, not a complete screen-reader/device audit. Leave records have their own Time off history; the coverage-only notification bell is unchanged, and no email or OS notifications are added. Payroll, leave balances, recurring leave, manager-created leave, editing saved leave, and emergency overrides are outside this increment. Existing coverage-linked shifts retain their editing restrictions and may need the existing coverage workflow resolved before leave can be approved. Reloading loses unsaved in-memory form data; saved records remain available. This JSON-backed application still uses a single server with persistent local storage. Passing these finite checks does not prove every future integration bug-free.
