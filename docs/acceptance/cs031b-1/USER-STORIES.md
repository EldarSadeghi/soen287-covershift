## Checks

- `npm run verify`: syntax checks and **161 tests passing**, including **12 new** employee search/integration/state tests. Log: verification.txt.
- Real GPT-6 Luna, fictional records: **7/7 cases pass**, details in live-evaluation.json. Each request uses the configured key server-side; no credentials or raw authorization headers are stored in evidence.
- Browser: successful existing-shift search, Cancel, exact Confirm, pending receipt, My requests persistence, no assignment transfer, free refresh after reload; isolated fake-provider failure tests distinguish UI recovery from real-model evaluations.
- Browser fault test: rejected 409 and a committed request with a response delayed 20 seconds. The 15-second client deadline shows uncertainty, persists across reload, removes repeat controls and does not automatically retry. The data check found exactly one pending claim.
- Responsive/keyboard checks use the in-app browser; viewport override reset after testing. Desktop and mobile controls remain reachable in the scrolling transcript.

## Limits and deferred work

Natural-language extraction can still misunderstand a request; the visible exact criteria and explicit confirmation are essential. Only one start date, optional explicit bounds and literal title keyword are supported. Unsupported constraints ask clarification. Chat shows at most ten eligible matches with a truthful count and Open shifts fallback; it does not paginate. A saved receipt records submission, not live approval status: My requests is authoritative.

Availability rules, automatic future matching and new in-app notifications are not part of this increment. No new database schema or deployment. Physical-device keyboards, VoiceOver and other browser engines have not been newly certified here. Existing browser-based accessibility checks are limited to the documented viewport and keyboard scenarios. AI-unavailable browser QA also verified preserved unsent text and manual Open shifts guidance (ai-unavailable.png). Provider request caps are not exact dollar tracking. CS-018 remains last.
